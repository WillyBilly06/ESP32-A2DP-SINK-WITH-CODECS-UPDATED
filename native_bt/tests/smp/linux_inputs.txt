The worker also needs the project's existing complete SDK mbedTLS source tree,
including its CMake files, include/, library/ and 3rdparty/ directories, at:

esp-idf/components/mbedtls/mbedtls/

Alternatively set DBT_SMP_MBEDTLS_SOURCE to that same SDK mbedTLS source tree
already present on the Linux machine. Do not substitute a different version
without reporting it. No BTstack source or headers are used.

Requirements: Linux, GCC with libasan, CMake, Ninja, Python 3 and the Python
cryptography package. From the workspace root run:

python3 native_bt/tools/test_smp_linux.py

The driver compiles only into native_bt/_build/smp/, runs the state and crypto
tests with the real SDK mbedTLS worker plus the in-memory NVS shim under ASan
and UBSan, and checks workspace budgets. LeakSanitizer is disabled because
CPython loads the instrumented libraries. The NVS shim is not flash testing;
the driver does not connect to hardware, store credentials, or alter daemons.
