The new dbt_a2dp_select_exact is a bounded metadata matcher for a caller-specified exact AVDTP Codec category body. It chooses a compatible local Sink SEID for one discovered, available audio Source endpoint. Codec identity comes from media type, codec type and the full vendor/codec tuple where applicable, not the SEID number or Android codec enum. It requires both mandatory Transport and Codec services. A parsed capability message alone is not a compatible selection.

Each actual codec validator checks the requested selection against local capabilities and a normalized view of the peer offer. This reuses supported codec/range/field rules instead of duplicating them or blindly ANDing numeric limits and identity bytes. The output reserves nothing: the peer can change state and still reject later Set Configuration.
