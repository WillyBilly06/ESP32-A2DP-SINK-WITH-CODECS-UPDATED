Once accepted, Abort is irreversible. Local state stops admitting media, while command release and primary ABORT worker cleanup can progress independently. The wire reservation is released on the next owner iteration without waiting for worker READY. Backend READY must acknowledge all older decoder/renderer ownership. A state that already has no live worker records worker_not_needed rather than inventing a completion receipt. Cancellation, General Reject, timeout or failed cleanup retires the affected profile; the old stream is not falsely reported restored.

Its key is retained in the existing profile storage and its expected lifetime in the caller context. A pending channel that opens after Abort is never rebound: the owner requests its closure. Normal cancellation of a never-opened channel can emit FAILED with NORMAL/status0, so that expected pending lease is classified by reason/status. A real connection/security/protocol/timeout failure remains an error. Raw event/reason/status stays recorded.

Pending media setup is cancelled as wire submission begins. Established media closure is requested after peer Abort Accept. Decoder release and media retirement proceed independently; terminal success requires peer acceptance, actual release READY or recorded no-worker-needed state, and retirement of every expected media lease. Early media closure keeps configuration/context reserved until these joins finish. A media timer starts only when closure is requested; before that, command transmit/response and backend deadlines own progress. No old deadline or zero timestamp masquerades as timeout.
