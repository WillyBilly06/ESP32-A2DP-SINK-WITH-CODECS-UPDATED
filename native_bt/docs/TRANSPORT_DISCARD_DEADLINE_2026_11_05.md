# Transport discard deadlines and bounded TX spans — 2026-11-05

The runtime wait calculation skipped every RX partial with a null data pointer. Oversized PDUs deliberately keep their handle/generation/CID/length/cursor/deadline without allocating payload storage, so they were omitted from the owner wakeup deadline. An otherwise idle host could sleep past the 1000 ms reassembly timeout until unrelated work arrived. The RX expire function already recognized this discard state; the wait path did not.

The wait predicate now matches the RX owner: a partial is active when data is present or expected exceeds max_pdu_payload. A bufferless discard contributes the same wrap-safe deadline as a normal partial. A due deadline returns zero; the next bounded runtime poll expires it, clears expected/received and increments abandoned. Subsequent waits can sleep again. Cleanup requires neither controller readiness nor ACL credits. No polling interval, task, buffer, timeout-length change or allocation is introduced.

TX packet assembly previously selected header/prefix/body for every copied byte. It now copies at most three intersecting spans: the four-byte L2CAP header, optional copied prefix and immutable borrowed payload. For a valid PDU of size S (including prefix P), the selected logical bytes are the slice [cursor,cursor+min(4+S-cursor,ACL_MTU)) of header||prefix||body. The bounded spans retain header/prefix splits, empty body and continuation behavior. Prefix extent, size and body presence are checked before output writes. Integer offsets are computed before pointer addition, keeping intermediate source pointers within their objects. Scratch/output-count disjointness from descriptor/ACL/borrowed payload is an explicit caller precondition; the product uses its existing separate reusable TX buffer.

Peek still does not advance the cursor. Only a successful ACL transport submission commits bytes. In the gated runtime send path, controller readiness is checked before reusable storage can be overwritten, and ACL pool admission remains separate. No source codec framing, payload limit, quality, rate/depth/bitrate, pool size or borrowed SDU lifetime is lowered. The TX change removes per-byte dispatch; a measured speed improvement is not established.
