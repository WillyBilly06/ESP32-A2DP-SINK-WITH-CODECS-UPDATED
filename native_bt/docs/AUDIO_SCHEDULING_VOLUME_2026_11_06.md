## Experimental host CPU budget

It creates one persistent one-shot esp_timer at initialization, with a1000us elapsed-work threshold and500us requested release. It activates only for high-rate LHDC with low Core1 output, retaining controller23,host22,decoder21,renderer20. The timer callback only publishes release and notifies the owner.
