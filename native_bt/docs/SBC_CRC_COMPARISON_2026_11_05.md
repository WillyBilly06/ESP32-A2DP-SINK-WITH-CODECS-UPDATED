# SBC checksum comparison and reduction

The BTstack reference at 9edb5d82ea6ec4466a393415d65030929330acdf calls its standalone OI SBC backend from src/classic/btstack_sbc_decoder_bluedroid.c:229–324. The SDK OI backend used here independently validates CRC in decoder-sbc.c:299–305 and uses nibble arithmetic in framing.c. The owned media layer previously used one bit recurrence per protected bit, repeated in packet preflight, resumable frame selection and decoder admission. All validation passes remain. No BTstack implementation is integrated.

The owned replacement is derived from the polynomial recurrence with feedback 0x1d, initial value 15, MSB-first order. For a four-bit input n, linearity gives S^4(c XOR (n<<4)) = ((c<<4) mod 256) XOR T[(c>>4) XOR n], where S shifts once with polynomial feedback and T[k] is S applied four times to k<<4. The 16 table entries were generated from that recurrence. Two four-bit advances process a byte in the same order as the original bit loop. Four-subband joint stereo ends on the high nibble; its low nibble remains outside the checksum exactly as before.

The validated SBC dimensions permit 32, 48, 52, 80 or 88 protected bits. The replacement performs 8, 12, 13, 20 or 22 four-bit advances respectively. Format, bitpool, bitrate, full-packet preflight, CRC comparison and OI decoder checks remain unchanged. Table indices are limited to 0–15 by private callers using a high nibble or low-nibble mask. The table is 16 constant flash bytes; no persistent mutable field, buffer, task, wait or queue is added.

Compiler-only experiments showed that forcing only the byte helper inline made the size optimizer emit calls to the nibble helper. Both tiny helpers are therefore forced inline. The candidate object contains only the existing dimensions call in dbt_sbc_frame_decode; the byte loop has no helper call. Target symbol sizes and final linked code are recorded in ignored build evidence. Static instruction counts and arithmetic step counts are not a measured playback speedup. No cycle/frame, underrun or acoustic improvement is claimed.

The user hold on separate unit, packet-injection, pairing and playback campaigns remains in force. Compilation/static analysis, flash integrity and ordinary startup are recorded separately; built-in startup codec checks run on boot. Full SBC error/reconnect/fragment/stress qualification remains outstanding.
